## 5. Theory: Amazon S3 vs Amazon EC2

| Amazon S3 | Amazon EC2 |
|---|---|
| Object storage service | Virtual computing service |
| Stores files and objects | Runs applications |
| Uses buckets | Uses instances |
| Used for backups and website files | Used for servers and application hosting |

### Real-World Example
An online shopping website can use Amazon S3 to store product images and Amazon EC2 to run its application.

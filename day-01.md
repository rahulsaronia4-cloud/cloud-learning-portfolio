## Task 2: Networking Basics
**Difficulty:** Easy  
**Status:** Completed

- Practised `ipconfig` to view network configuration.
- Practised `nslookup google.com` to check DNS resolution.
- Practised `ping google.com` to test network connectivity.

**What I learned:**
- IP address identifies a device on a network.
- DNS translates domain names into IP addresses.
- Ping checks whether a destination responds over the network.

**Skill improved:** Basic networking troubleshooting.

## Task 5: Cloud Computing Theory
**Difficulty:** Easy  
**Status:** Completed

- **Cloud Computing:** Using computing services such as servers, storage and databases over the internet.
- **IaaS:** Infrastructure as a Service — provides virtual servers and networking. Example: Amazon EC2.
- **PaaS:** Platform as a Service — provides an environment to build and deploy applications. Example: Google App Engine.
- **SaaS:** Software as a Service — ready-to-use software over the internet. Example: Gmail.

**Skill improved:** Cloud computing fundamentals.

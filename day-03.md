# Day 3 – Cloud Computing Practice

## Task 1: File Permissions
- Used `icacls` to check file permissions.
- Used `whoami` to identify the current Windows user.
- Understood Full Control (F) permission.

## Task 2: Network Ports and Connections
- Used `netstat -ano` to view network connections.
- Used `netstat -ano | findstr LISTENING` to filter listening ports.
- Learned about TCP, UDP, ports, states and Process IDs (PID).

## Task 3: Cloud Deployment Planning
- Created `cloud-deployment-plan.txt`.
- Planned to host a static website using Amazon S3.
- Identified website storage, access URL and basic security considerations.

## Task 4: Cloud Regions and Availability Zones
- Learned what a Cloud Region is.
- Learned what an Availability Zone (AZ) is.
- Understood how multiple AZs can improve application availability.
- Learned that backups and replication are important for data protection.

## Day 3 Learning Outcome
Practised Windows file permissions and network monitoring, created a basic cloud deployment plan, and understood cloud infrastructure availability.

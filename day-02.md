## Task 2: Networking Fundamentals

Commands practised:
- `ipconfig`: Displays network configuration.
- `nslookup google.com`: Checks DNS resolution.
- `ping google.com`: Tests network connectivity.

Key concepts:
- IP address identifies a device on a network.
- DNS translates domain names into IP addresses.
- Subnet mask identifies network and host portions of an IPv4 address.
- Default gateway forwards traffic to other networks.

**Practical result:** DNS resolution succeeded, and ping received 4 replies with 0% packet loss.

## Task 5: Cloud Deployment Models

### Public Cloud
- Provides computing services using a cloud provider's infrastructure.
- Multiple customers use the provider's infrastructure with logically separated resources.
- Examples: AWS, Microsoft Azure and Google Cloud.

### Private Cloud
- Dedicated to a single organization.
- Provides greater control and customization.
- Can be hosted on-premises or by an external provider.

### Hybrid Cloud
- Combines public cloud services with private cloud infrastructure.
- Allows organizations to choose suitable environments for different workloads.
- Example: Hosting a public website in the public cloud while keeping sensitive systems in a private environment.
